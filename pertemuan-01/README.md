# pertemuan-01
1. Konsep Dasar Pemrograman Web<br>
Jawaban: Pemrograman web adalah kegiatan membuat aplikasi/situs yang berjalan melalui internet dan diakses lewat browser.<br>
2. Arsitektur Klien-Peladen<br>
Jawaban: Klien yaitu perangkat pengguna yang biasanya berupa browser, klien meminta halaman dan menampilkan tampilan web. Peladen yaitu server yang menyimpan file, memproses, dan mengirim balik hasilnya ke klien.<br>
3. HTTP Request dan Response<br>
Jawaban: Request yaitu permintaan yang dikirim oleh klien (browser) ke server untuk meminta data, sedangkan Response yaitu balasan dari server kepada klien setelah menerima dan memproses request.<br>
4. HTML, CSS, JavaScript, PHP, MySQL<br>
Jawaban: HTML yaitu tulang/struktur dari suatu web/aplikasi. CSS yaitu untuk mengatur tampilan dari web/aplikasi supaya terlihat menarik. JavaScript yaitu untuk membuat web/aplikasi supaya lebih interaktif seperti tombol, animasi, dan responsive. PHP yaitu suatu bahasa pemrograman server untuk memproses logika dan data. MySQL yaitu sistem database untuk menyimpan dan mengelola data.<br>
5. Hubungan Antarteknologi<br>
Jawaban: Klien membuka browser -> browser mengirim request ke server -> PHP di server memproses permintaan, jika perlu mengambil/menyimpan data dari MySQL -> server membentuk halaman menggunakan HTML, CSS, JavaScript -> server mengirim halaman jadi sebagai response ke klien (browser) -> browser menampilkan halaman ke pengguna.<br>
